## Pagination Project in CodeIgniter 3

### Project Overview
This project demonstrates the implementation of pagination in a REST API using CodeIgniter 3 as part of the "Art of Living" initiative.

### Endpoints Overview

- **View Users (Main List):**
  - Localhost:  
    `http://localhost/1_api/pgination_CI/index.php/api/users`
  - Production:  
    `https://krishnendudalui.in.net/API_pagination/index.php/api/users`

- **View a Single User:**
  - Localhost:  
    `http://localhost/1_api/pgination_CI/index.php/api/users/view`
  - Production:  
    `https://krishnendudalui.in.net/API_pagination/index.php/api/users/view`

- **Paginated User Retrieval via Postman:**
  - Example Request:
    - Localhost:  
      `http://localhost/1_api/pgination_CI/index.php/api/users?limit=4&page=1`
    - Production:  
      `https://krishnendudalui.in.net/API_pagination/index.php/api/users?limit=4&page=2`

- **View User by ID:**
  - Localhost:  
    `http://localhost/1_api/pgination_CI/index.php/api/userbyid/1`
  - Production:  
    `https://krishnendudalui.in.net/API_pagination/index.php/api/userbyid/1`

- **Delete Employee via API Consumer:**
  - Localhost:  
    `http://localhost/1_api/API_Consumer/delete_employee/13`

---

### Key Concepts for Pagination
- **Limit:** Records per page  
- **Offset:** Number of records to skip  
- **Page Number:** Current page in pagination  
- **Total Records:** Total records in the database  
- **Total Pages:** Pages available based on the limit  

### Testing via Postman
Use this endpoint with query parameters for testing:
- Example:  
  `http://localhost/1_api/pgination_CI/index.php/api/users?limit=4&page=1`  
Adjust the `limit` and `page` parameters as required.
